# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html),
and is generated by [Changie](https://github.com/miniscruff/changie).

## <a name="v0.6.0">v0.6.0</a> - 2026-08-06
### Added
- Add portable board backups with committed attachments and resumable, non-destructive restores.
### Changed
- Order issue lists by creation time unless an explicit sort is requested.
### Fixed
- Stream board copies in bounded batches instead of loading the complete board into memory.

## <a name="v0.5.1">v0.5.1</a> - 2026-08-04
### Fixed
- Allow hyphenated source names in aggregate web mode.
- Fix an empty board selector in direct web views of multi-board stores.

## <a name="v0.5.0">v0.5.0</a> - 2026-08-03
### Added
- Display Cardamom branding in Codex plugin and skill surfaces.
- Add `card web --source` for read-only dashboards over Cardamom web servers.

## <a name="v0.4.0">v0.4.0</a> - 2026-08-01
### Added
- Preview issue titles and workflow metadata when hovering or focusing issue references.
- Show when each non-empty issue State was last updated beside its heading.
- Add a favicon to the web view.
### Changed
- Navigate with board-scoped web paths and bookmarkable result filters. Label links preserve Board or List from those views and open List from other pages.
### Fixed
- Let linked Git worktrees inherit the primary checkout's selected board until they choose their own.
- Keep issue and object reference pills mounted when rendered Markdown rerenders.

## <a name="v0.3.0">v0.3.0</a> - 2026-07-31
### Added
- Add `card web --read-only` to keep browser reads and attachment downloads available while rejecting operations that may change Cardamom state.
- Add a Settings option to show empty Kanban columns.
- Show issue containment breadcrumbs with titles on hover.

## <a name="v0.2.0">v0.2.0</a> - 2026-07-31
### Changed
- Board switching now uses a searchable, project-aware header selector on desktop and mobile.
### Fixed
- Truncate long issue labels in Kanban cards instead of widening the board.
- Report development builds as `dev`, show the running Cardamom version in Settings, and keep wide issue log content within narrow viewports.

## <a name="v0.1.1">v0.1.1</a> - 2026-07-30
### Fixed
- Allow `card web` to start on a multi-board shared store so the browser can select its scope.
- Keep `card web` serving and report a warning when the browser cannot be opened automatically.
- Remove the unnecessary configuration dependency from `card web` startup.

## <a name="v0.1.0">v0.1.0</a> - 2026-07-30
### Added
- Show the active board, issue, or settings context in browser tab titles.
- Create and list project namespaces in an existing Cardamom store with `card project create` and `card project list`.
- Distribute Cardamom as self-hosted Claude and Codex plugins with automatic CLI bootstrap.
- Add `card skill install` to install the embedded Cardamom skill into a caller-selected skills directory.
### Changed
- Reorganize issue pages around compact metadata, chronological history, pinned State, and collapsible Details and Relations sections.
- Teach Cardamom agents to preserve coherent phase outcomes without turning incomplete mechanics or long-running commands into progress checkpoints.
- Open issue Relations by default and remember the user's expansion choice across issue pages.
### Fixed
- Include maintained release notes in published GitHub releases.
- Release binaries report their published version instead of a development build identifier.
- Allow `card web` to serve a new empty store without creating a project or board.

## <a name="v0.1.0-beta.2">v0.1.0-beta.2</a> - 2026-07-29
### Added
- Publish a Homebrew Cask on release.
### Changed
- Fresh `card init` projects infer an issue ID prefix from the selected directory when no store prefix is active. Use `--prefix` to set a project override.

## <a name="v0.1.0-beta.1">v0.1.0-beta.1</a> - 2026-07-29

Initial release.
