---
title: Install
description: Install the clu CLI and (optionally) the bundled web UI.
---

## From a clone

```bash
make install
```

This runs `go install ./cmd/clu` to put the binary on your `PATH`, then runs
`clu web --install` which builds the bundled TanStack web UI and copies the
output to `~/.local/share/clu/web`. The web-UI step is skipped silently if
`pnpm` is not on `PATH` — the CLI still works.

## CLI only

```bash
go install github.com/rovak/clu/cmd/clu@latest
```

Make sure `$HOME/go/bin` is on your `PATH`. Verify with:

```bash
clu --help
```

## Requirements

- Go 1.22 or newer.
- (Optional) `pnpm` if you want the bundled web UI built during `make install`.

There is no CGo dependency — `clu` uses the pure-Go SQLite driver
`modernc.org/sqlite`.
