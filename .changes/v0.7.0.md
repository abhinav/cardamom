## <a name="v0.7.0">v0.7.0</a> - 2026-08-11
### Added
- Add `card project edit` to rename projects while preserving their identity, boards, configuration, and creation time.
- Add `card project show` to inspect project metadata, effective project configuration, and its boards without selecting a board.
- Allow config show, set, and unset to target a project without selecting a board.
- Add board archiving to hide boards from active lists without deleting their issues and restore them later.
### Changed
- Show the Git revision, dirty state, and build timestamp in `card version` when available.
- Make bare `card state commit` clear current State after preserving it in Log.
- Load web pages on demand to reduce the browser work required at startup.
### Fixed
- Show waiting reasons in issue details, boards, lists, and issue-reference previews.
