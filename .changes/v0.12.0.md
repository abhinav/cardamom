## <a name="v0.12.0">v0.12.0</a> - 2026-10-29
### Added
- Add `card board clone` to create local replicas with shared identities, retained mutation history, and attachment content.
### Changed
- Board copies and portable restores now assign new board identities even when the source identity is unused in the destination store.
### Removed
- Remove `card board copy`. Use `card board clone` to create a replica in another local store while preserving board and issue identities and mutation history.
### Fixed
- Make source filters in the aggregate web board catalog work and show each board's source.
- Avoid scanning the entire database when commands open a store whose schema is already current.
